# Решения (ADR-lite)

## 2026-09-13
1. **Одна коллекция Weaviate, `domain` = атрибуция чанка** (имя каталога корпуса). Классификатора нет. `QueryRequest.domain` — опциональный фильтр по чанк-домену; значение `"DefaultDocuments"` (легаси клиента) = без фильтра.
2. **Модели через OpenAI/Cohere-совместимый HTTP, провайдер per-компонент через env.** По умолчанию всё на OpenRouter одним ключом: `qwen/qwen3.8-flash` (chat), `qwen/qwen3-embedding-8b` (embeddings, 4096 dims), `qwen/qwen3-reranker-8b` (rerank, `POST /rerank`). Для локального тестирования — `compose.models.yml`: три `llama-server` с открытыми весами (Qwen3.8-27B GGUF вместо закрытой Flash, Qwen3-Embedding-8B GGUF, Qwen3-Reranker-8B GGUF), те же контракты. Реранкер также `grpc` (rag-services) или `none`. gRPC-эмбеддинг удалён. (Уточнение 2026-09-13: ранний вывод «OpenRouter не отдаёт embeddings» был ошибкой — они в отдельном списке `/api/v1/embeddings/models`.)
3. **Перебор моделей** — смена env + `scripts/run_control_questions.py`; смена эмбеддера требует `load_corpus --recreate`.
4. **Чанкинг:** `MarkdownHeaderTextSplitter` h1–h3 + breadcrumb; `md_chunk_size=1800/200`, порог предупреждения 4000 (лимит 512 токенов старого эмбеддера снят). На текущем корпусе = 154 чанка при любом размере ≥ 900.
5. **Гейт B (вычитка корпуса) отложен** — грузим как есть; места «на слух» в `oreo-data/GATE-B-REVIEW.md` ждут видео.
6. **Прод (Yandex Cloud) выключен** — автодеплой при push в main игнорируем, deploy.yml не переделываем.
7. **PR #12 (doc-arag) и PR #6 (rag-services) мержим** — правило «не мержить до T7» снято пользователем.
8. Сабагенты: sonnet-5 / opus-5, не fable-5.1.
9. **Golden set** хранится в `oreo-data/golden/` (данные рядом с корпусом), собирается из `parts/*.jsonl`; каждая запись проверяется против корпуса (`must_include` дословно в источнике, `section` — реальный заголовок). Метрики: doc_hit@k, domain_hit@k, fact_coverage, forbidden, опционально LLM-judge 1–5 по эталону. `/query` отдаёт `sources` ради retrieval-метрик.
10. **Локальные модели на Mac — llama.cpp нативно на Metal** (`scripts/local_models.sh`), api в docker ходит на `host.docker.internal`. Проверено по документации: Docker Desktop даёт GPU контейнерам только на Windows/WSL2; SGLang на Apple Silicon есть лишь нативно через MLX (сборка из исходников, без embeddings/rerank), docker-образы SGLang — CUDA (arm64-теги под Grace/DGX Spark). **SGLang — для GPU-сервера** (`compose.sglang.yml`). Локальный генератор — открытая Qwen3.8-27B (Flash закрыта), пользователь ожидает, что она слабее; сравниваем на golden set.

## 2026-09-14
11. **Диалоговые сессии — в Weaviate, вне графа LangGraph.** Каждый чат клиента = `session_id` в `/query`; без него запрос stateless (скрипты eval не затронуты). Коллекция `ChatMessages` без векторов (`Configure.Vectors.self_provided()`, векторы не передаём), **один объект = одно сообщение** (append без read-modify-write, `delete_many` по `session_id` и по `updated_at` для TTL), summary — отдельная строка с детерминированным uuid5. TTL 7 дней ручным sweep при старте и раз в час (native ObjectTTL Weaviate не задействован — молодая фича). Формат памяти: последние 6 сообщений дословно (обрезка 1200 символов только в промпте) + скользящее LLM-summary старых после 12 сообщений, обновляется fire-and-forget после ответа. `rephrased_query` = standalone-вопрос, разрешённый по истории (его эмбеддим, реранкаем, оцениваем); попутно закрыт баг бесполезных итераций. Без LangGraph checkpointer: процесс-локален или новая БД, тащит эмбеддинги в чекпоинт, не даёт читаемой истории. Store за протоколом (`SESSION_STORE=weaviate|memory`); падение store деградирует ответ до stateless, а не роняет запрос.

## 2026-09-15
12. **Auth для MVP — Authelia за Caddy `forward_auth`, не Keycloak и не свой сервис.** Аутентификация и грубая авторизация (группа `admins` на `/api/uploads|embeddings|documents`) — на границе (репо `doc-arag-client`); бэкенд читает `Remote-User`/`Remote-Groups` (`src/docarag/auth.py`, `AUTH_TRUSTED_HEADERS=true`) и сам проверяет группу, `GET /me` — для UI. Граница доверия — общий секрет `AUTH_PROXY_SECRET` в заголовке `X-Auth-Proxy-Secret`, который ставит Caddy: docker-сеть `arag-common-network` общая с клиентом и sterility-ai, и без секрета любой соседний контейнер подделал бы заголовки. Порты api/weaviate/minio дополнительно привязаны к `127.0.0.1`. Скрипты ходят в API с тем же секретом (`scripts/api_auth.py`). Корпоративный IdP Эр-Телеком неизвестен; если понадобится SAML/ADFS — Keycloak вместо Authelia, приложение не меняется. Эндпоинты `/sessions/{id}` (решение №11) при вливании поставлены на `user_router`: читать и удалять историю может только вошедший пользователь; проверка владельца (`owner` у сообщений) пока не сделана — в backlog.
13. **Независимый judge — Claude Opus 5 через сабагентов**, а не через API: агенты читают корпус целиком и оценивают ответы по эталону и по корпусу, Qwen-оценка скрыта. Результат v3: Opus 4.73 против self-judge 4.66 — самооценка Qwen не завышена. Заодно агенты вычитывают golden (см. `.claude/reports/golden-v3-opus-judge.md`).
14. **Чанкинг: мелкие соседние секции склеиваются** (`md_merge_sections=True`, потолок `md_merge_max_size=1000`, одиночная длинная секция по-прежнему до `md_chunk_size=1800`). Причина: файлы вида «Стадия 1…11» резались на чанки по ~350 символов, соседние шаги не попадали в контекст (conn-006), а «следующая стадия» домысливалась (conn-002). Потолок 1800 пробовали — точечные вопросы тонут в больших чанках (conn-002 упал до 1). Корпус: 154 → 92 чанка.
15. **Retrieval по двум векторам** (`retrieval_use_original_query=True`): оригинальный вопрос и перефраз ищутся отдельно (k=20 каждый), кандидаты объединяются по uuid с лучшим score, затем rerank. Перефраз иногда уводил от второго документа (cross-doc, diag-010).
16. **Golden: `must_include` может быть взят из `alt_sources`**, для `cross-doc` второй файл обязан лежать в `alt_sources` и давать хотя бы один `must_include`. Правки 22 записей по замечаниям Opus-судьи: короткие основы слов вместо косвенных падежей, эталон не шире вопроса, неоднозначные вопросы уточнены (tarif-010, diag-006, diag-009), tarif-008 — эталон покрывает обе причины.
17. **v5 принят базовой конфигурацией** (Opus 4.74 против 4.73 у v3 и 4.65 у v4). Склейка секций остаётся: стадии подключения выиграли (connection-process 4.17 → 4.67), а регрессию v4 сняли правила промпта. В промпте генерации запрещены домыслы («подразумевается», «чаще всего»), собственные советы, ранжирование причин без опоры на текст и перенос навигации между «Лапой» и BG Billing; перед «в базе нет» модель проверяет все фрагменты.
18. **Поиск по двум векторам оставлен включённым, но пользы не доказал**: diag-010 по-прежнему не находит ticket-systems.md. Выключить или подтвердить — отдельной абляцией.
19. **Для решений по генерации — только Opus-судья.** Qwen-самосудья не увидел регрессию v4 (4.65 против 4.66) и ставит оценки с разбросом ±1 на корпусно верных ответах.
20. **Деплой — на чистый CPU** (Selectel, 2 vCPU / 4 ГБ / 25 ГБ): все три модели по API OpenRouter, на сервере api, Weaviate, MinIO, клиент и Caddy. Rerank 8B на CPU не проходит по задержке.
21. **На OpenRouter генератор работает без размышлений** (`LLM_EXTRA_BODY={"reasoning": {"enabled": false}}`): по умолчанию Qwen3.8-flash тратит большую часть токенов на reasoning, пробный вопрос шёл 180 с и стоил в 5 раз дороже. Локально Qwen тоже без thinking — сравнение честное. Пустой `LLM_EXTRA_BODY` из compose теперь означает «не задано».

## 2026-09-16
22. **Провайдер эмбеддингов на OpenRouter закреплён** (`EMBEDDING_EXTRA_BODY={"provider": {"order": ["nebius", "deepinfra"], "allow_fallbacks": false}}`): без него часть запросов уходила на провайдера с задержкой до 25 с, а SiliconFlow отдаёт fp8 — векторы индекса и запросов должны приходить с одной модели.
23. **Создание коллекций терпит гонку процессов**: продовый образ запускает `uvicorn --workers 2`, оба процесса на пустом Weaviate создают `DefaultDocuments`/`ChatMessages`, проигравший получал 422 «already exists» и ронял api. 422 с «already exists» теперь = успех.
24. **Сквозная проверка — локальная копия прода** (продовый образ и compose, Authelia на `oreo.test`), браузер через Playwright; до деплоя повторять её после изменений в auth, Caddy или клиенте.
